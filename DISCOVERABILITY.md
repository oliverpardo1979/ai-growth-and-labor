# Bibliographic discoverability

The public digital-edition entry page provides the complete approved abstract in server-delivered HTML, Highwire citation tags, DOI, ORCID, Schema.org ScholarlyArticle JSON-LD, and a BibTeX download. It links directly to the stable PDF and SSRN record. These changes support discovery, not a guarantee of ranking or indexing.

When changing the approved title, author, abstract, publication dates or DOI, update the static fallback and bibliographic metadata in docs/index.html and citation.bib together with the generated manuscript. Preserve the preprint status until journal publication is confirmed. Do not list Journal of Economic Growth as the publication venue while the paper is under review.

Publish metadata edits using the same immutable snapshot process described in WEB_EDITION.md. A main-branch docs edit alone is not published.

The sitemap is available at https://oliverpardo1979.github.io/ai-growth-and-labor/sitemap.xml. Google and other services determine when to crawl it. Do not claim that a sitemap, structured data, or an author-profile edit changes external rankings immediately.
